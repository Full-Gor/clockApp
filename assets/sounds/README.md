# Sons d'alarme

Placez vos fichiers MP3 dans ce dossier pour les utiliser comme sons d'alarme.

## Sons par défaut recommandés

Vous pouvez télécharger des sons d'alarme gratuits depuis :
- https://pixabay.com/sound-effects/search/alarm/
- https://freesound.org/search/?q=alarm
- https://www.zapsplat.com/sound-effect-category/alarms/

## Fichiers recommandés à ajouter

1. `classic.mp3` - Son d'alarme classique
2. `gentle.mp3` - Son doux pour un réveil en douceur
3. `bell.mp3` - Son de cloche
4. `chime.mp3` - Carillon
5. `beep.mp3` - Bips répétés

Tous vos fichiers MP3 dans ce dossier seront automatiquement détectés et disponibles dans l'application.
